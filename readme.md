# 📝 To-Do List Application

A simple task management application that helps users organize and manage their daily activities.

## ✨ Features
- Add new tasks.
- Delete tasks.
- Mark tasks as completed.
- View pending tasks.
- Simple and clean interface.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🎯 Objective
To make daily task management easier and improve productivity.

## 👨‍💻 About
A beginner-friendly project developed to practice JavaScript DOM manipulation, event handling, and CRUD operations.
